## Figure 1

GCC attention is represented by processed sampling-point tables. Thresholds are <150, 150–3,000 and >3,000 records. The marginal profile is derived from the original 451,643 geolocated study-location records, filtered to the displayed latitude range and binned in 1-degree latitude and 2-degree longitude bins. Only bin counts are distributed in `profile_histogram.csv`; no individual article-location records are included. The original five-bin smoothing is retained. The Lorenz curve is supplied as a processed table.

## Figure 2

The Sankey input contains aggregate flows for the 655,275 jointly valid GCC points. The code checks the common total and the highlighted conditional percentages (51.4% and 38.6%). The BBI input contains processed point-level burdens. Regional counts and IPCC boundaries support panel c. Natural Earth land geometry is supplied as a plotting reference. IPCC boundaries are copied from the project's CVI regional-boundary input; consult the manuscript for source attribution and original use conditions.

## Figure 3

Population and GDP inputs are processed panel source tables. Map sites are screened plotting coordinates rather than complete station archives. Footprints define the 1,000 km geodesic windows. Regional source tables supply the four-network inventory index, attention totals and growth measures. Correlation summaries retain the upstream bootstrap intervals and associated statistics. The renderer uses these results; it does not rerun the original 20,000 bootstrap resamples or 99,999 permutations.
